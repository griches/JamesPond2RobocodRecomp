# Fonts

- `Inter-Regular.ttf`, `Inter-SemiBold.ttf`: Inter by The Inter Project Authors, SIL Open Font License 1.1 (`Inter-OFL.txt`).
- `MaterialSymbolsRounded-subset.ttf`: Material Symbols Rounded by Google, Apache License 2.0 (`MaterialSymbols-LICENSE.txt`), cut down to the icons the menu uses with fontTools' subsetter.

All are built into the program (see `tools/embed.cmake`).
